# Vanilla Normals Renewed — 1.21.11 / 512x Pipeline

## 支持版本
- 主目标：**Minecraft Java 1.21.11** (`pack_format=75`)
- `supported_formats` 允许较旧加载器回退检测（55–75）

## 推荐加载器与光影
- Iris + Sodium（推荐）
- OptiFine（兼容）
- 支持 LabPBR 的现代光影（Complementary/SEUS PTGI 等）

## PBR 规范（LabPBR 导向）
- `*_n.png`: 法线图（Tangent-space normal）
- `*_s.png`: 复合 PBR 图（本包约定）
  - R: AO
  - G: Roughness
  - B: Metalness
  - A: Height/Parallax height
- `*_e.png`: Emissive 图（由 `optifine/emissive.properties` 的 `_e` 后缀启用）


## 让方块纹理更显眼（新增）
- `enhance_pbr.py` 新增 `--detail-profile`：`soft / balanced / bold`。
- 默认使用 `bold`，并且对 `textures/block/**` 自动应用更高局部细节倍率（约 1.35x），提升边缘起伏和材质层次。
- 如需更夸张效果可提高 `--detail-boost`（如 `1.25`），如需更克制可降到 `0.9`。


## 资产生产阶段（英雄方块优先）
1. 阶段A（英雄方块 30+）：
```bash
python scripts/enhance_pbr.py --phase hero --theme theme.json --emissive-level 4 --include-items --force-item-reflective
```
2. 阶段B（扩全包）：
```bash
python scripts/enhance_pbr.py --phase all --theme theme.json --emissive-level 4 --include-items
```

## Emissive 强度分级（1–5）
1. 非常弱（仅暗处可见）
2. 弱（矿物边缘微亮）
3. 中（默认，细节可见不过曝）
4. 强（高科技/末地/红石核心）
5. 极强（仅用于极少数高亮材质）

## 一键流程
```bash
python scripts/run_all.py
```

### 分步执行
```bash
python scripts/upgrade_to_512.py --target 512
python scripts/enhance_pbr.py --emissive-level 3 --detail-profile bold --detail-boost 1.15
python scripts/audit_resolution.py
python scripts/audit_references.py
python scripts/build_release.py --version 1.21.11-1
```


## 仓库策略
- 不提交二进制 zip 到 Git 历史。
- 发布包由 `python scripts/build_release.py` 本地/CI 生成。


## 英雄物品反光（新增）
- 新增 `scripts/hero_items.txt`，优先强化锭/工具/盔甲/宝石等物品的反光表现。
- 可通过 `--force-item-reflective` 强制 item 走高反光路径。
