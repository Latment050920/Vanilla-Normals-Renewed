# Vanilla Normals Renewed — 1.21.11 / 512x Pipeline

## 支持版本
- 主目标：**Minecraft Java 1.21.11** (`pack_format=75`)
- `supported_formats` 允许较旧加载器回退检测（55–75）

## 推荐加载器与光影
- Iris + Sodium（推荐）
- OptiFine（兼容）
- 支持 LabPBR 的现代光影（Complementary/SEUS PTGI 等）

## PBR 规范（LabPBR 导向）
- `*_n.png`: 法线图（Tangent-space normal）
- `*_s.png`: 复合 PBR 图（本包约定）
  - R: AO
  - G: Roughness
  - B: Metalness
  - A: Height/Parallax height
- `*_e.png`: Emissive 图（由 `optifine/emissive.properties` 的 `_e` 后缀启用）

## Emissive 强度分级（1–5）
1. 非常弱（仅暗处可见）
2. 弱（矿物边缘微亮）
3. 中（默认，细节可见不过曝）
4. 强（高科技/末地/红石核心）
5. 极强（仅用于极少数高亮材质）

## 一键流程
```bash
python scripts/run_all.py
```

### 分步执行
```bash
python scripts/upgrade_to_512.py --target 512
python scripts/enhance_pbr.py --emissive-level 3
python scripts/audit_resolution.py
python scripts/audit_references.py
python scripts/build_release.py --version 1.21.11-1
```
